FX ORBIT — GITHUB WEBSITE PACKAGE

1. Unzip this archive on your computer.
2. Add the fx-orbit folder to the published website directory in your repository. This is the folder containing the live homepage index.html (often the repository root, docs, or public).
3. Keep index.html and assets inside fx-orbit; upload the entire folder.
4. In your existing homepage navigation, insert this link immediately AFTER ProOrchestral:

<a href="/fx-orbit/">FX Orbit</a>

5. Commit the changes and wait for your existing website deployment.
6. Open https://orchestralpro.com/fx-orbit/

No changes to DNS or the existing ProOrchestral homepage are needed.
This is a static HTML page with local images. If your repository builds a framework app, place fx-orbit in its public/static directory so the folder is copied to the published output.
The existing navigation styling should be applied to the new link.

The new product page includes ProOrchestral and FX Orbit links in that order.
